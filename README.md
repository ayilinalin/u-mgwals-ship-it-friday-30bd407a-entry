## What it does

`main.py` (Python 3, standard library only, no network) writes a single line —
the funniest git commit message an AI coding agent writes right before it
breaks production on a Friday — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change the output directory (default `/output`).
